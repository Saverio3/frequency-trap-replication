# Real Robyn code, daily vs weekly data (Reviewer 1, point 2). Design fixed BEFORE the run (24 Oct 2026)

Software: Robyn 3.12.1 R source from Meta's GitHub (raw files), installed from source in R 4.3.3 with glmnet 4.1-8, prophet 1.0, reticulate 1.35, Nevergrad 1.0.12 (numpy 1.26). The only change to Robyn: its helper package lares (used for printing, plotting, clustering and string helpers) is replaced by a minimal stand-in; clustering is therefore switched off. The Robyn modelling code (transformations, ridge by glmnet, objectives, TwoPointsDE through Nevergrad, Pareto step) is unmodified. One DESCRIPTION edit: the patchwork version floor was relaxed (plots only).
Data: simulated single-channel markets exported by export_robyn_markets.py: daily KPI and daily spend, and the SAME data summed to weeks. Truth daily (geometric adstock, Hill with gamma at the P50 of adstock), signal R2 0.85, 156 weeks. Daily KPI = baseline/7 + response + noise with no weekday effect. Markets used here: pattern in {bursty, real}, delta {0.15, 0.50, 0.85}, shape {1.0, 2.2}, one replication = 12 markets: ids 0,4,6,10,12,16,18,22,24,28,30,34.
Arms: Robyn on weekly data (prophet trend and season) and Robyn on daily data (prophet trend, season, weekday), the practitioner's actual choice.
Held constant: simulated market, hyperparameter bounds (alpha 0.5-3, gamma 0.05-1, theta 0.01-0.95, train_size 0.5-0.9; the same numeric bounds for both frequencies), time-series validation on, seed, iterations per run, 1 trial, search algorithm (TwoPointsDE), ridge through glmnet, Pareto step.
NOT held constant: number of observations (7x as many in the daily run), Prophet decomposition (weekday term only for daily), the meaning of theta at the two frequencies (weekly theta is about daily theta to the 7th), glmnet lambda path (depends on n). 
Deviation from Robyn's recommendation: 1000 iterations and 1 trial instead of 2000 x 5, because of compute (about 2.5 minutes per run on two cores). Convergence is therefore NOT assured; the paper must say so, and a convergence check on 4 markets with 4000 iterations follows.
Selection rules: lowest validation NRMSE among Pareto-1 models, and lowest Robyn error_score (identical in practice with one channel, because DECOMP.RSSD is zero for a single channel). Estimate = Robyn's xDecompAgg for the channel (sum over the window of coefficient times saturated adstock). Metric: contribution bias % against the true total; paired weekly minus daily |bias|, 2-SE rule (with 12 markets the standard error will be large; this is a feasibility-scale result, not a replacement for the 10,000-market studies).
Expectations (reported either way): Robyn adds substantial error relative to the grid arms; daily is better than weekly on average but not in every market.

## Notes added during the runs (24 Oct 2026)
1. The first attempt (results/RBREAL_1000.csv) produced 7 runs (markets 0, 4, 6 both frequencies, market 10 weekly) before its job ended; an earlier note said 3 runs. The job was restarted from scratch with a resumable wrapper (run_robyn_all.sh -> results/RBREAL_1000_full.csv), same script, same settings, all 12 markets.
2. Same-seed repeats do NOT reproduce each other (Nevergrad's search is not controlled by Robyn's seed under two worker processes). The seven repeated (market, frequency) cells from the two attempts are therefore used as a direct measure of run-to-run noise. The MAIN comparison uses the second attempt (RBREAL_1000_full.csv: one run per market and frequency); the first attempt is reported separately as a replication. Declared before the main run finished.
3. Estimator for the comparison: lowest validation NRMSE among Pareto-1 models (the error_score rule is identical in practice for one channel).
